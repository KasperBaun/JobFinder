# Danish glossary

Danish copy is **not** a word-for-word rendering of the English. Write what a Danish
product would say, then check it against this list so the same concept never gets two
words. Trim: English marketing cadence reads as padding in Danish.

## The one that bites

English overloads "rating". Danish must not.

| Concept | English | Danish |
|---|---|---|
| The 0–1 number the ranker computes | rating / score | **score** |
| The user's own good/bad judgement of a job | rating / mark | **vurdering** |

So: `Bedste vurdering` was wrong for a top score — it reads as "your best judgement".
It is `Højeste score`. `Din vurdering` (the mark column) stays `vurdering`.

## Register

- Informal **du**, never "De".
- Imperatives for actions: `Kør en søgning`, `Gem`, `Vælg`.
- No stiff officialese ("foretage", "anvende") — use `gøre`, `bruge`.
- Keep technical nouns English where Danish developers do: API, RSS, endpoint,
  sitemap, JSON-LD, and ATS product names.
